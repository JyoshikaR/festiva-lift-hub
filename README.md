# Festiva: Festival Lift

Create a modern, premium, responsive website prototype called “Festiva – Smart Festival Marketplace & Festival Lift Analytics”, closely inspired by the attached reference image.

IMPORTANT: Use the attached reference image as the visual design inspiration. Recreate the overall structure, spacing, card layout, navigation style, colorful festival visuals, analytics section, and professional marketplace appearance, but improve it with more festivals, better icons, richer images, and polished interactions.

PROJECT GOAL:

Festiva is a smart festival marketplace where customers can discover festival-specific products, while businesses can understand how much product demand increases during festival periods. The main hackathon concept is “Festival Lift Quantifier”.

TECHNOLOGY:

- HTML5

- CSS3

- JavaScript

- No backend initially

- Use realistic JavaScript/JSON mock data

- Organize code so Node.js + Express + MySQL can be added later

- Prepare a dedicated Power BI dashboard section

- Use local/online image assets appropriately

- Make the prototype fully responsive
